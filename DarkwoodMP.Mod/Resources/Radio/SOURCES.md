# Radio sound sources

Recordings embedded in the DLL. Each was trimmed, mixed to mono and converted to
44.1 kHz 16-bit PCM.

| File | Used for | Source | Author | Licence |
|------|----------|--------|--------|---------|
| `key.wav` | Talk key pressed | [Walkie Talkie famous beep](https://freesound.org/people/SEF7/sounds/701326/) | SEF7 | CC0 1.0 |
| `release.wav` | Talk key released | [Radio Sign Off / Squelch](https://freesound.org/people/JovianSounds/sounds/524205/) | JovianSounds | CC0 1.0 |
