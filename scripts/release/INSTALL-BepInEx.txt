YokWare Branch {VERSION} - co-op multiplayer for Darkwood (BepInEx build)
Wire protocol {PROTOCOL}. Every player in a session needs this same version.

WHAT IS IN THIS ZIP
  DarkwoodMP.Mod.dll   the mod
  LiteNetLib.dll       its network library (required)
  LICENSE              GPLv3

INSTALL
1. Install BepInEx 5.x (5.4.23 or newer 5.4.x, NOT BepInEx 6) into your Darkwood folder:
   https://github.com/BepInEx/BepInEx/releases
   Pick the build for how you run the game (Windows x64, or Linux x64 for the native
   Linux game). Launch the game once so BepInEx creates its folders, then quit.
2. Copy DarkwoodMP.Mod.dll and LiteNetLib.dll into Darkwood/BepInEx/plugins/
3. Launch Darkwood.
   - Linux native with Steam: set the Steam launch options to
       ./run_bepinex.sh %command%
     (a plain Steam launch skips BepInEx).
   - Windows game under Proton/Wine: set the launch options to
       WINEDLLOVERRIDES="winhttp=n,b" %command%
4. Check: MULTIPLAYER under PLAY on the title screen shows "YokWare Branch {VERSION}"
   at the bottom.

Use one loader per game install. Do not also install the MelonLoader build.
To update, replace both DLLs. To uninstall, delete them.

PLAYING
- Host: MULTIPLAYER > Host > Local network or Steam, then pick a profile.
  Friends can join once you are in the world.
- Join over Steam: MULTIPLAYER > Join > Steam friends, or accept the host's invite.
- Join over LAN/VPN: MULTIPLAYER > Join, type the host's address (port 7788).
  GOG copies have no Steam and join over LAN.
- Keys: Esc pause menu (MULTIPLAYER inside), F4 spectate, Ctrl+C text chat,
  V push-to-talk.
- Only the host saves. Your character comes back when you rejoin the same host.

SETTINGS
  Darkwood/BepInEx/config/com.yokware.branch.cfg (created on first launch;
  most options are also in MULTIPLAYER > Settings)

REPORTING A BUG
Send Darkwood/BepInEx/LogOutput.log from every player, right after the problem and
before starting the game again (it is overwritten on each launch). Say who hosted
and what each player did.
